# Shortcuts

**Explorer**

- `F2` - Open / close (you can change it in Settings)
- `Click` / `Ctrl+Click` / `Shift+Click` - Select, add to the selection, select a range
- `Right-Click` - Context menu
- `Arrows` / `Home` / `End` / `Page Up/Down` - Move through the tree
- `Enter` - Expand, or reveal a search result
- `F` / `Ctrl+F` - Focus the camera on the selection / search
- `Ctrl+Z` / `Ctrl+Y` - Undo / redo
- `Ctrl+C` / `Ctrl+V` / `Ctrl+Shift+V` - Copy / paste next to / paste into
- `Ctrl+D` / `Delete` - Duplicate / destroy
- `Drag rows onto a row` - Move them into it
- `Middle Click a tab` - Close a tool
- `Double-Click the title bar` - Full screen / back

**Command line**

- `Ctrl+Enter` - Run (or press Run)
- `Ctrl+Up` / `Ctrl+Down` - History
- `Ctrl+Space` - Suggestions
- `Tab` / `Up` / `Down` - Take a suggestion, move through them
- `Ctrl+/` - Comment lines out, or back in
- `Ctrl+]` / `Ctrl+[` - Indent / outdent
- `Alt+Up` / `Alt+Down` - Move lines
- `Shift+Alt+Up` / `Shift+Alt+Down` - Copy lines
- `Ctrl+Shift+K` - Delete lines
- `Shift+Alt+F` - Format
