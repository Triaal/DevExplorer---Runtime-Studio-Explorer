# FAQ

### What's the performance of this?
When making this, optimization was the main thing I kept in mind. The explorer is heavily optimized and doesn't affect regular players who don't have access to it.

### Can exploiters use it?
The server performs sanity checks and can't be exploited at all, as long as the permissions is properly set, nothing on the server can be manipulated by the client.

### Is the command line safe?
The command line is turned off by default, however if you turn it on, whoever has permission essentially has the power to do anything, so be cautious of who you give executor perms to.
